# -nginx
用C++实现一个多线程高并发服务器程序框架，只需要添加业务逻辑就可以利用本项目完成实 工作中诸多服务器项目开发，如网络游戏、通信服务器等。
又思维导图可以看

技术实现：

1.架构与事件驱动：基于 Epoll LT + 非阻塞 Socket 构建多线程 Reactor 事件循环，完成 Master / Worker 进程生命周期组织与主链路分发；单机支撑 10,000+ 并发连接，峰值 QPS 达 67,000+，P99 延迟 < 2ms。

2.协议解析：设计“定长包头 + 变长包体”协议，结合有限状态机（FSM）精准处理 TCP 粘包与拆包，明确消息边界，有效杜绝半包/错包导致的解析异常。

3.连接管理：设计连接池与异常连接延迟回收机制，引入序列号校验防止旧连接复用风险，及时清理僵死连接，保障长连接服务的极高稳定性。
